# Breakline · 키움 최고가 돌파 매매

국내·미국 주식과 ETF를 검색하고, 설정 화면에서 입력한 **최고가 돌파율·매입 비율·손절률**로 매매하는 로컬 웹 프로그램입니다. 기본 대상 범위는 **전체 시장 자동 검색**이며, 처음 실행하면 실제 주문을 보내지 않는 모의 모드의 정지 상태로 시작합니다.

**실제 시세 모의투자**는 키움의 실제 종목명·시세와 가상 현금으로 정수 수량을 계산합니다. 종목별 평가금액·평가손익과 원화·달러별 합계를 표시하며, 예제 연습 장부는 별도로 보존합니다. [실제 시세 모의투자 안내](docs/paper-trading.md)에서 시작 순서와 평가 계산을 확인하세요. [PC 백그라운드 실행](docs/background.md)을 사용하면 브라우저와 실행 창을 닫아도 PC가 켜져 있는 동안 계속 감시할 수 있습니다.

키움 공식 REST API의 국내·미국 주식 기능과 실시간 체결 구독 어댑터를 구현했습니다. 실제 계좌 인증, 전체 시장 구독 허용 범위, 실제 주문·체결은 사용자 API 키와 권한으로 추가 검증해야 합니다. 키 없는 예제 실행과 모의 응답 테스트의 성공이 실거래 검증을 뜻하지는 않습니다.

[사진으로 보는 업데이트·실행 방법](docs/screenshots.md)을 따라 진행할 수 있습니다. 아래는 실제 프로그램에 검증용 데이터를 넣어 촬영한 화면이며, 실제 현재 시세·계좌 잔고가 아닙니다.

## 구현된 동작

| 항목 | 동작 |
| --- | --- |
| 검색 대상 | 키움이 반환한 KOSPI·KOSDAQ·ETF, 미국 ND·NY·NA 거래소의 주식·ETF 목록. 미국 ETN은 제외 |
| 최고가 | 각 시장의 전 거래일까지 완료된 상장 이후 수정 일봉 최고가. 오늘 일봉은 제외 |
| 매수 | 직전 관측값이 기준선 미만이고 새 가격이 기준선 이상인 **상향 돌파**에서 주문 |
| 매입 비율 | 해당 주문 시점의 남은 주문 가능 현금에 적용. 수수료 여유금과 미체결 예약금 반영 |
| 통화 | 국내 KRW와 미국 USD를 분리. 원화 자동 환전이나 달러 대신 원화로 주문하는 기능 없음 |
| 손절 | 실제 체결 평균가 기준의 손절선 이하에서 해당 종목 전량 매도 주문 |
| 추가 설정 | 종목별 추가 매수, 손절 후 재매수 대기시간, 최대 보유 종목 수, 수수료 여유율 |
| 복구 | 설정·주문·부분 체결·잔고를 로컬 SQLite에 저장. 실제 시세 모의 감시만 선택한 자동 복구 요청에 따라 재개. 실거래는 항상 정지 상태로 재시작 |

돌파율 `-2%`도 입력할 수 있습니다. 역대 최고가가 10,000원이면 기준선은 9,800원이며, 가격이 그 선 **아래에서 위로 넘어올 때** 매수합니다. 처음 본 가격이 이미 기준선 위에 있다고 바로 매수하지 않습니다.

## 설치와 실행

### Windows: start.bat 더블클릭

Python **3.11~3.13**을 설치한 뒤, 프로그램 폴더의 **[start.bat](start.bat)을 더블클릭**하세요. `start.bat`은 `launch.py`, `pyproject.toml`과 같은 폴더에 있어야 합니다. PowerShell에 실행 명령을 입력하거나 `uv` 경로를 따로 설정할 필요가 없습니다.

처음 실행할 때 필요한 의존성이 없으면 자동으로 설치하므로 인터넷 연결이 필요합니다. 준비가 끝나면 Brave의 일반 설치 위치를 확인해 Brave로 화면을 열고, 찾지 못하면 Windows 기본 브라우저로 엽니다.

기본 주소는 `http://127.0.0.1:8000`입니다. 다른 프로그램이 사용하거나 Windows가 예약한 포트로 확인되면 **8001~8010번 중 빈 포트**를 찾아 그 주소를 브라우저로 엽니다. 이후 더블클릭하면 이 프로그램이 실행 중인 주소를 찾아 재사용합니다. 포트 번호를 직접 입력할 필요가 없습니다.

기존 설치를 업데이트할 때는 일반 실행 창에서 **Ctrl+C**, 백그라운드 실행은 **stop-background.bat**으로 종료합니다. [GitHub 저장소](https://github.com/roy888682/kiwoom_buy_sell)의 **Code → Download ZIP**으로 받은 파일을 다른 임시 폴더에 압축 해제하고, 그 안의 파일과 폴더를 기존 프로그램 폴더에 복사해 같은 파일을 덮어씁니다. 기존 폴더 자체를 지우거나 새 폴더와 바꾸지 마세요. 개인 키가 있는 `.env`, 거래 기록이 있는 `data`, 설치 환경 `.venv`는 그대로 보존합니다. 화면 파일만 바꾸면 새 기능이 동작하지 않으므로 Python 파일과 실행 파일도 함께 업데이트합니다.

- 서버를 시작한 실행창은 프로그램을 사용하는 동안 열어 두세요. **브라우저만 닫아도 서버는 계속 실행됩니다.**
- 실행창에서 **Ctrl+C**를 누르면 이 실행기가 시작한 서버를 종료합니다.
- 서버가 이미 정상 실행 중이면 기존 서버를 재사용합니다. 이때 기존 서버를 종료하려면 그 서버를 처음 실행한 창에서 중지하세요.
- 첫 실행은 화면에서 **감시 시작**을 직접 누릅니다. 이후 **실제 시세 모의투자**의 자동 복구를 켜고 감시를 시작한 기록이 있으면, 서버 재실행 시 그 모의 감시 요청을 재개할 수 있습니다. 화면의 **감시 중지**를 누르면 재개 요청도 해제됩니다. 실거래는 자동으로 시작하지 않습니다.
- 같은 데이터 폴더는 서버 하나만 사용하도록 잠급니다. 수동 실행한 서버와 실행기도 이 잠금을 공유합니다. 이전 버전의 응답 없는 Python 서버로 의심되면 다른 서버를 만들지 않고, 이전 실행 창을 종료하도록 안내합니다.

바탕화면에서 실행하려면 `start.bat`을 마우스 오른쪽 버튼으로 눌러 **보내기 → 바탕 화면에 바로 가기 만들기**를 선택하세요. Windows 11에서는 먼저 **추가 옵션 표시**를 눌러야 할 수 있습니다.

검은 실행 창도 닫고 싶다면 **[start-background.bat](start-background.bat)**을 사용합니다. 준비가 끝나 브라우저가 열린 뒤에는 실행 창과 브라우저를 닫아도 PC가 켜져 있고 절전 상태가 아니면 계속 실행됩니다. 종료할 때는 **[stop-background.bat](stop-background.bat)**을 누릅니다. Windows 로그인 시 자동 실행 방법과 복구 동작은 [백그라운드 실행 안내](docs/background.md)에 있습니다.


### Linux / macOS

Python **3.11~3.13**과 [uv](https://docs.astral.sh/uv/getting-started/installation/)가 필요합니다. 아래 명령은 저장소 최상위 폴더에서 실행합니다. 기존 `.env`는 덮어쓰지 않습니다.

```bash
git clone https://github.com/roy888682/kiwoom_buy_sell.git
cd kiwoom_buy_sell
uv sync --frozen
[ -f .env ] || cp .env.example .env
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저가 자동으로 열리지 않으면 실행 창에 표시된 주소를 브라우저 주소창에 입력합니다. 직접 실행할 때 `--port 8000`을 사용했다면 주소는 `http://127.0.0.1:8000`입니다. 서버는 실행한 터미널에서 계속 동작해야 합니다. API 키를 입력하거나 변경했다면 서버를 다시 시작하세요.

Brave에서도 실행 창에 표시된 주소를 새 탭의 주소창에 입력하면 됩니다. 보통 `http://127.0.0.1:8000`이며, 자동으로 다른 포트를 선택했다면 그 주소를 사용하세요. 채팅 안의 웹 미리보기와 별도로 열리며, `F11`로 전체 화면을 사용할 수 있습니다. 화면 글자는 초기 화면의 1.6배(직전 확대 화면의 80%)를 기본으로 사용하며, 각 영역은 배경색과 테두리로 구분합니다. **샘플 초기화**와 **돌파 시나리오 실행**은 주문 내역 아래의 **버튼 사용법만 연습하기** 영역에 있습니다.

화면에 **연결 끊김**이 표시되면 평소 사용하던 **start.bat** 또는 **start-background.bat**을 다시 실행합니다. 일반 실행은 검은 실행 창을 열어 두세요. 브라우저에는 서버가 종료되기 전 화면이 남아 있을 수 있습니다. 연결이 돌아오면 화면은 상태를 다시 읽으며, 감시 시작이나 주문 요청을 중복 전송하지 않습니다. 서버의 모의 감시 자동 복구는 별도로 저장한 설정에 따릅니다. 하단의 **최근 동기화**는 한국 시간의 연월일·시분초를 표시하고, 연결이 끊긴 동안에는 마지막으로 확인한 시각을 유지합니다.

이 프로그램에는 사용자 로그인 기능이 없습니다. `127.0.0.1` 바인딩을 유지하고 공개 서버나 외부 포트로 노출하지 마세요. 계정 한 곳에 서버 프로세스 하나만 실행하며, 여러 uvicorn worker를 사용하지 않습니다.

## 키 없이 먼저 확인하기

1. 대시보드의 **샘플 초기화**를 누릅니다. 모의 현금은 KRW 1,000만 원, USD 1만 달러입니다.
2. 돌파율 `2`, 매입 비율 `30`, 손절률 `5`를 확인하고 설정을 저장합니다.
3. 실행 모드 **모의 거래**, 시세 선택 **예제 가격 연습**을 확인하고 **감시 시작 → 돌파 시나리오 실행**을 누릅니다.
4. 국내·미국 가상 종목의 매수, 통화별 잔액, 실제로 적용한 모의 체결 평균가와 손절선을 확인합니다.
5. 감시 종목의 모의 가격 입력으로 손절선 이하 가격을 보내 전량 매도 흐름을 확인할 수 있습니다.

샘플은 가격 규칙을 확인하는 가상 자료입니다. 전체 시장 검색 결과나 키움 모의투자 체결 자료가 아닙니다. 모의 체결은 입력 가격에서 즉시 체결된 것으로 가정하며, 설정한 수수료 여유율을 모의 수수료로 사용합니다.

실제 종목·가격으로 연습하려면 시세 종류를 **실제 시세 모의투자**로 선택하고 키움 키를 설정한 뒤 감시를 시작합니다. 현재 시세가 이미 돌파 기준선 위에 있거나 전체 수정 이력이 확인되지 않으면 자동 매수하지 않습니다. 키움 모의투자 서버에 주문을 보내는 기능과는 별개이며, 가상 현금과 가상 체결만 기록합니다.

## 키움 연결과 전체 시장 검색

연결 순서, 환경 변수, 미국 시세 시간대 확인, 주문 대조 방법은 **[키움 연결 안내](docs/kiwoom-connection.md)**에 있습니다. 계산식·예외 처리·CSV 형식은 **[매매 규칙](docs/strategy.md)**을 참고하세요.

키가 연결되면 전체 종목 목록을 가져와 상장 이후 수정 일봉을 검증합니다. 초기 준비는 종목 수와 이력 길이에 따라 오래 걸립니다. REST 요청은 기본적으로 최소 0.25초 간격으로 직렬 처리하고, 보유 잔고·주문 조회도 같은 제한을 공유합니다. 일봉 준비가 끝나면 적격 종목과 보유 종목에 국내 `0B`·미국 `FE` 실시간 구독을 요청합니다.

전체 목록을 받았다는 사실만으로 전체 시장의 모든 틱을 받는다고 표시하지 않습니다. 제공 이력, 미국 상장일, 시세 권한, 구독 승인 종목 수를 확인해야 합니다. 이력이 부족한 종목은 매수하지 않으며, 구독 거절·연결 공백·처리 대기열 초과 시 감시를 정지합니다. 실제 시세 모의투자만 선택한 자동 복구 설정에 따라 재시도하며, 구독 승인 후 첫 시세는 새 기준 관측값으로 사용합니다.

## 실거래 전 확인할 점

- 실거래 시작 시 계좌의 기존 현금 보유 종목도 가져오며 **그 종목들에도 손절 규칙이 적용됩니다.** 별도 계좌 사용을 권장합니다.
- 감시 중지는 새 매매 판단과 손절 감시를 모두 멈춥니다. 이미 키움에 접수된 미체결 주문은 자동 취소되지 않습니다.
- 손절률은 주문을 내는 기준입니다. 급락, 호가 공백, 거래정지, 장 마감, 체결 지연 시 실제 손실은 설정값보다 커질 수 있습니다.
- 프로그램 실행 중 다른 HTS·MTS에서 수동 거래하면 잔고 대조 오류로 자동매매가 정지할 수 있습니다.
- 이 버전은 실제 계좌·시장 데이터로 장기 운영 검증을 마친 배포 제품이나 수익을 보장하는 전략이 아닙니다. 먼저 모의 실행과 조회 권한을 확인하세요.

테스트는 돌파·음수 돌파율·현금 배분·예약금·부분 체결·손절·재매수 대기, 거래소 휴일, CSV 이력 검증, HTTP와 실시간 시세 프로토콜의 모의 응답, 애플리케이션 API를 검사합니다. 실제 인증이나 실제 주문은 테스트에서 실행하지 않습니다.

브라우저 회귀 검증은 CI의 별도 작업에서 실행합니다. 로컬에서는 `uv run --with playwright==1.62.0 python -m playwright install chromium`으로 테스트용 브라우저를 준비한 뒤 `uv run --with playwright==1.62.0 python -m unittest discover -s tests -p test_dashboard_browser.py -v`를 실행합니다. 모의 감시·체결, 한국 시간 날짜 표시, 응답 유실과 연결 복구 시 요청이 중복 전송되지 않는지를 확인합니다.

| 파일 | 역할 |
| --- | --- |
| `start.bat`, `launch.py` | Windows 더블클릭 실행, 필요한 의존성 준비, 서버 확인 및 브라우저 열기 |
| `start-background.bat`, `stop-background.bat`, `background.py` | 창을 닫아도 계속 실행하는 로컬 서버의 시작·종료 |
| `app/main.py` | 로컬 API, 검색·실시간 감시·주문 조정 |
| `app/strategy.py` | Decimal 기반 매매 규칙과 누적 체결 장부 |
| `app/valuation.py` | 종목별 평가금액·평가손익, 통화별 합계와 시세 신선도 계산 |
| `app/marketdata.py` | 거래일·정규장·수정 최고가·CSV 검증 |
| `app/kiwoom.py` | 키움 OAuth·조회·주문 REST 어댑터 |
| `app/stream.py` | 실시간 구독 승인·체결 수신·공백 감지 |
| `app/storage.py`, `data/` | 로컬 SQLite 상태 저장; `data/`는 Git 제외 |
| `app/static/` | 설정·검색·계좌·주문 화면 |

API 키는 `.env` 또는 실행 환경의 비밀 값으로만 설정합니다. `.env`, 계좌 DB, 토큰을 GitHub나 채팅에 올리지 마세요. 저장소에는 값이 비어 있는 `.env.example`만 포함합니다.
