# 실제 시세로 모의투자하기

**실제 시세 모의투자**는 키움이 제공하는 실제 종목명과 시세를 사용하고, 프로그램 안의 가상 현금으로 매매를 계산합니다. 키움 계좌에 주문을 보내지 않습니다. 키움 모의투자 서버에 주문을 접수하는 방식도 아닙니다.

## 시작 순서

1. 프로그램 폴더의 `.env`에 `KIWOOM_APP_KEY`, `KIWOOM_SECRET_KEY`를 입력합니다. 모의투자용 키를 받았다면 `KIWOOM_ENV=mock`, `ALLOW_LIVE_TRADING=false`를 유지합니다.
2. 기존 서버를 종료하고 프로그램을 다시 실행합니다.
3. 화면 위쪽 실행 모드를 **모의 거래**, **시세 선택**을 **실제 시세 모의투자**로 선택합니다.
4. **투자 시장**을 선택합니다. 모의 API의 미국 시세 제공 범위가 확인되지 않았다면 **국내 주식 · ETF**로 먼저 조회를 확인합니다. 국내·미국 전체를 탐색하려면 **국내 + 미국**을 선택합니다.
5. 초기 가상 현금은 원화 1,000만 원, 달러 1만 달러입니다. 금액을 바꾸려면 정지 상태에서 **모의 자금 설정 · 초기화**를 누르고 시작 금액과 `모의투자 초기화`를 입력합니다. 초기화하면 해당 모의 장부의 보유·주문·손절 대기 기록이 지워집니다.
6. **감시 시작**을 누릅니다. 전체 시장 설정에서는 선택한 시장의 공식 종목 목록과 수정 일봉 이력을 확인한 뒤 실시간 구독을 요청합니다. 이력 조회는 종목 수에 따라 오래 걸릴 수 있습니다.

화면에 키가 설정되었다고 표시되는 것만으로 인증이 확인된 것은 아닙니다. 검색 결과, 오류 메시지, 실제 시세 시각과 구독 승인 수를 확인하세요. **국내 + 미국**은 탐색 범위입니다. 전체 종목 목록을 받았더라도 이력이 부족하거나 구독이 승인되지 않은 종목은 매수할 수 없습니다. 미국 시세 권한·모의 서버 지원 여부·체결 시각의 시간대는 [키움 연결 안내](kiwoom-connection.md)에 따라 확인합니다. 운영 시세가 필요하면 운영용 키와 `KIWOOM_ENV=live`를 사용하되, 모의투자를 할 때는 `ALLOW_LIVE_TRADING=false`와 화면의 **모의 거래**를 유지합니다.

## 가격과 수량 계산

- 이름은 키움의 종목 목록을 사용합니다.
- 종목별 가격은 키움에서 받은 체결 시각이 검증된 가격을 사용합니다. 수동 입력·예제 가격으로 실제 시세 모의 주문을 만들 수 없습니다.
- 새 매수에는 정규장, 최근 90초 이내 시세, 실시간 구독 승인, 당일 기준으로 확인된 전 거래일까지의 수정 최고가 이력이 필요합니다.
- 첫 시세가 이미 돌파선 위에 있어도 바로 사지 않습니다. 새 시세가 돌파선 아래에서 위로 넘어올 때 판단합니다.
- 매입 비율에 따른 예산에서 수수료 여유분을 반영하고, 살 수 있는 **정수 주수**만 계산합니다. 원화·달러 예산은 각각 계산합니다. 예를 들어 가상 예산이 300만 원이고 1주 가격이 10,200원이면 수수료 여유분을 포함해 살 수 있는 주수를 정합니다. 실제 계좌의 현금이나 보유 수량을 가져오지는 않습니다.
- 모의 주문은 판단한 시세에 전량 체결된 것으로 가정하고, 설정한 **수수료 · 여유금 비율**을 모의 수수료로 차감합니다. 실제 호가 대기·체결 지연·부분 체결·세금을 모두 재현하는 방식은 아닙니다.
- 보유 중 주식분할·병합에 따른 가상 수량·평균가 조정과 배당금 반영은 아직 자동화하지 않았습니다. 수정주가 최고가 검증과는 별개이며, 해당 기업행사가 생기면 감시를 멈추고 가상 장부를 확인해야 합니다.

기존 **예제 가격 연습**은 별도의 장부를 사용합니다. 예제 종목·가상 주문이 실제 시세 모의투자 잔고에 섞이지 않습니다. 이전 버전에서 만든 모의 거래 기록은 예제 장부에 보존합니다. 업데이트 후 예제 모드가 선택되어 있다면 감시를 멈추고 **실제 시세 모의투자**로 바꾼 뒤 다시 시작하세요.

## 보유 및 평가 화면

각 종목에 종목명·코드·보유 주수·평균 매입가·현재 평가가격·평가금액·평가손익·수익률·시세 시각을 표시합니다. 모의투자 화면의 주수와 평균 매입가는 가상 체결 기록이며, 실제 계좌의 보유 내역과는 별개입니다.

| 항목 | 계산 |
| --- | --- |
| 매입금액 | 보유 주수 × 평균 매입가 |
| 평가금액 | 보유 주수 × 최근 확인 가격 |
| 평가손익 | 평가금액 − 매입금액 |
| 총자산 | 가상 현금 잔액 + 보유 종목 평가금액 |

미체결 매수 예약금은 주문 가능 현금에서 제외하지만, 총자산에서 다시 빼지 않습니다. 거래 수수료는 현금에 반영되며, 종목 평가손익은 가격 변동 기준입니다. 원화 평가합계와 달러 평가합계는 분리합니다. 환율을 확보하지 않은 상태에서 두 통화를 더한 숫자는 표시하지 않습니다.

시세가 90초를 넘겨 오래되었거나 프로그램을 재시작해 새 시세를 아직 확인하지 못했다면 마지막 확인 가격과 시각을 유지하고 **오래된 시세**로 표시합니다. 평가할 가격이 없는 종목은 **시세 없음**으로 표시하고, 통화별 총 평가금액·총자산은 `—`로 남깁니다.

## 창을 닫아도 실행하기

[PC 백그라운드 실행 안내](background.md)를 참고하세요. 브라우저는 상태를 표시하는 화면이므로 닫아도 서버가 켜져 있으면 계속 감시합니다. 검은 실행 창까지 닫으려면 백그라운드 실행 파일을 사용합니다.

**연결 복구 후 자동으로 다시 감시**를 켜고 실제 시세 모의 감시를 시작했다면, 연결 오류 후 대기 시간을 늘리며 재시도합니다. 재시도 대기 중에는 매수·손절 감시도 멈춰 있습니다. 서버를 다시 시작했을 때도 저장된 모의 감시 요청을 재개합니다. 이때 최신 이력과 새 시세를 다시 확인하며, 신규 매수는 다시 관측한 아래→위 돌파가 필요합니다. **감시 중지**를 누르면 재개 요청도 해제됩니다. 실거래는 자동 복구나 재시작으로 시작하지 않습니다.

PC가 꺼지거나 절전·최대 절전 상태가 되면 감시할 수 없습니다. 인터넷 끊김·키움 점검·거래소 휴장 중에는 새로운 시세 기반 주문을 만들지 않습니다. 24시간 프로그램을 켜두는 것과 주식을 24시간 거래할 수 있는 것은 다릅니다.

PC를 꺼두고도 계속 실행하려면 고정 송신 IP를 갖춘 별도 서버가 필요합니다. GitHub는 이 저장소의 코드를 보관하는 곳이며, GitHub Actions는 실행 시간 제한과 임시 실행 환경 때문에 상시 투자 서버로 사용하지 않습니다. 서버 운영 시에는 로컬 바인딩을 유지하고 SSH 터널로 접속하며, `.env`·SQLite 데이터·실행 로그를 공개 저장소에 올리지 마세요.
