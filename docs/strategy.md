# 매매 규칙과 데이터 기준

## 돌파 매수

`H`는 해당 시장의 **전 거래일까지 완료된 상장 이후 수정 고가의 최댓값**, `b`는 설정한 돌파율입니다.

```text
돌파 기준선 = H × (1 + b / 100)
매수 신호 = 직전 관측 가격 < 돌파 기준선 ≤ 새 관측 가격
```

예를 들어 `H=10,000원`이면 `b=2%`의 기준선은 10,200원, `b=-2%`의 기준선은 9,800원입니다. 음수 돌파율도 같은 **상향 교차** 규칙을 사용합니다.

최초 시세, 재시작 후 첫 시세, 새 일봉 기준을 적용한 뒤 첫 시세는 관측 기준만 만듭니다. 첫 관측 가격이 이미 기준선보다 높으면 매수하지 않습니다. 기준선 아래로 내려왔다가 다시 위로 넘어오는 새 관측이 필요합니다. 같은 가격이 반복되거나 계속 기준선 위에 있는 것만으로 추가 매수하지 않습니다.

전체 시장 목록에서 이력 검증을 통과한 종목을 검색·구독합니다. 실제 매수는 해당 실시간 스트림이 준비되고 시세 시각·정규장 여부가 확인된 뒤에만 허용합니다. 과거 일봉으로 당일의 실시간 돌파가 발생했다고 소급 주문하지 않습니다.

## 남은 현금으로 주문 수량 계산

`C`는 주문 시점의 해당 통화 주문 가능 현금, `a`는 매입 비율, `P`는 주문 가격, `f`는 수수료 여유율입니다.

```text
이번 주문 예산 = C × a / 100
1주당 여유금 포함 비용 = P × (1 + f / 100)
주문 수량 = floor(이번 주문 예산 / 1주당 여유금 포함 비용)
```

소수점 주식은 사용하지 않습니다. 1주를 살 수 없으면 주문하지 않습니다. 실거래에서는 키움의 종목·가격별 주문 가능 금액과 최대 가능 수량을 다시 확인해 수량을 제한합니다. 매수 주문끼리 현금을 중복 사용하지 않도록 예약하고, 실제 접수된 매수 주문의 체결·취소가 대조되기 전에는 같은 통화의 다음 매수를 보수적으로 대기시킵니다.

국내는 KRW, 미국은 USD 장부를 분리합니다. 원화 대용 주문 가능액, 신용 매수, 자동 환전은 사용하지 않습니다. 외부 미체결 주문에 묶인 금액은 브로커가 보고한 주문 가능액에 반영되어 있어야 하며, 로컬 예약금과 이중으로 차감하지 않도록 대조합니다.

수수료 여유율은 비용 확정치가 아닙니다. 모의 실행에서는 이 비율을 가정 수수료로 차감하고, 실거래는 실제 계좌의 주문 가능액과 체결·잔고 조회로 갱신합니다. 매수 평균가는 주문 희망가가 아닌 실제 체결가의 가중 평균을 사용합니다.

## 손절과 부분 체결

`A`는 현재 보유분의 실제 매수 평균가, `s`는 손절률입니다.

```text
손절 기준선 = A × (1 - s / 100)
손절 신호 = 새 관측 가격 ≤ 손절 기준선
```

손절 조건을 먼저 평가하며 이력 부족이 손절을 막는 사유는 아닙니다. 부분 매수 상태에서 손절이 발생하면 남은 매수 주문을 취소하고 경합 중 발생한 체결을 다시 대조한 뒤 실제 보유 수량을 전량 매도하도록 요청합니다. 이미 손절 매도 미체결 주문이 있으면 같은 매도 주문을 반복 제출하지 않습니다.

체결은 누적 수량·누적 금액으로 반영하므로 같은 응답을 재조회해도 체결을 두 번 더하지 않습니다. 부분 체결로 보유 수량과 평균가가 달라질 수 있습니다. 수량·잔고가 일치하지 않으면 임의로 맞추지 않고 자동매매를 정지합니다.

손절은 손실을 5%로 확정하는 장치가 아닙니다. 시장가 주문의 실제 체결 가격은 급락·유동성 부족·거래정지·장 마감 등으로 훨씬 나쁠 수 있습니다. 정규장 밖, 시세 검증 실패, 프로그램 정지·종료 중에는 자동 주문을 내지 않습니다.

## 입력 예시

| 설정 | 값 |
| --- | --- |
| 전 거래일까지 수정 역대 최고가 | 10,000원 |
| 돌파율 | 2% |
| 매입 비율 | 30% |
| 손절률 | 5% |
| 시작 주문 가능 현금 | 10,000,000원 |

가격이 10,200원 아래에서 10,200원 이상으로 올라오면 매수 신호입니다. 첫 주문 예산은 약 300만 원입니다. 실제 체결 평균가가 10,200원이라면 손절 기준은 9,690원입니다.

기본 수수료 여유율 `0.5%`를 적용한 모의 예에서는 292주를 주문합니다. 매수 금액 2,978,400원과 가정 수수료 14,892원을 차감하면 7,006,708원이 남고, 다음 종목 예산은 그 금액의 30%인 약 210만 원입니다. 실제 주문 가능 금액·가격·수수료·체결 잔량에 따라 결과는 달라집니다.

## 추가 설정

| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| 전체 시장 자동 검색 | 사용 | 키움이 반환한 전체 대상 목록을 준비하고 적격 종목을 구독 |
| 같은 종목 추가 매수 | 사용 안 함 | 켠 경우에도 새로운 상향 돌파가 있어야 추가 매수 |
| 손절 후 재매수 대기시간 | 60분 | 실제 손절 체결 시점부터 적용. 부분 손절이 추가 체결되면 그 시점으로 갱신 |
| 최대 보유 종목 수 | 5 | 국내·미국 합산. 보유 종목과 신규 매수 미체결 종목을 함께 계산 |
| 수수료 여유율 | 0.5% | 주문 수량 계산의 비용 여유금. 실제 수수료율 보장은 아님 |
| 확인 주기 | 15초 | 잔고·주문 대조 등 작업 주기. 실시간 스트림이 15초에 한 번만 수신된다는 뜻은 아님 |

대기시간이 끝났다고 자동으로 다시 매수하지 않습니다. 대기가 끝난 뒤 새 돌파도 필요합니다. 추가 매수로 실제 평균가가 바뀌면 손절 기준도 그 평균가로 바뀝니다. 설정은 자동매매를 정지한 상태에서 변경합니다.

## 거래일과 수정 가격

국내는 서울 시간과 KRX 거래일, 미국은 뉴욕 시간과 NYSE 정규장 달력을 사용합니다. NASDAQ 종목에도 같은 미국 정규장 달력을 적용합니다. 토·일요일이나 달력상 휴장일을 단순한 평일로 처리하지 않습니다. 미국 서머타임과 조기 폐장을 반영합니다.

최고가에서는 해당 시장의 오늘 일봉을 항상 제외합니다. 오늘 장이 마감되어도 그 시장의 전 거래일까지를 기준으로 삼으며, 새 시장 날짜에 수정 가격 기준을 갱신합니다. 주식 분할·역분할 등으로 이전 가격이 조정되면 오늘의 조정 기준으로 과거 고가도 비교해야 합니다.

프로그램은 상장일과 첫 일봉의 정합성, 전 거래일 일봉, 중간 거래일 누락을 보수적으로 확인합니다. 거래정지로 일봉이 빠진 종목도 완전성 검증을 통과하지 못할 수 있습니다. 이는 상장 이후 전체 이력을 확보한 것으로 잘못 판단하지 않기 위한 제외이며, 보완 데이터가 필요합니다.

## 가격 이력 CSV

UTF-8 CSV를 국내·미국 시장별로 나누어 정지 상태에서 가져옵니다. 한 번에 최대 25MB이며 같은 종목은 필요한 전체 이력을 한 묶음으로 포함하세요. 필수 헤더는 다음과 같습니다.

```csv
market,symbol,name,date,high,close,adjusted,complete_from_listing
```

선택 열은 `listing_date`, `exchange`입니다. 미국 `exchange`는 실제 키움 코드인 `ND`, `NY`, `NA`를 사용합니다. 국내 종목 코드는 앞자리 0을 보존한 6자리 문자열입니다.

```csv
market,symbol,name,date,high,close,adjusted,complete_from_listing,listing_date,exchange
US,EXAMPLE,형식 설명용,2026-10-16,100.00,99.00,true,false,,ND
```

위 행은 **형식 설명용 불완전 데이터**이며 실제 종목이나 완전한 상장 이력 예제가 아닙니다. `complete_from_listing=false`이므로 매수 대상이 되지 않습니다. 행 하나를 넣거나 플래그만 바꾼다고 상장 이후 최고가가 검증되는 것은 아닙니다.

| 열 | 의미 |
| --- | --- |
| `market` | `KR` 또는 `US` |
| `symbol` | 종목 코드 |
| `name` | 종목 이름 |
| `date` | 일봉 거래일, `YYYY-MM-DD` |
| `high`, `close` | 동일 조정 기준의 수정 고가·수정 종가. 유한한 양수이며 고가 ≥ 종가 |
| `adjusted` | 수정 가격일 때만 `true`. 수정하지 않은 CSV는 거부 |
| `complete_from_listing` | 제공자가 상장 이후 전체 수정 이력임을 확인했을 때만 `true` |
| `listing_date` | 선택. 정확한 상장일, 첫 거래일과 대조 |
| `exchange` | 선택. 국내 `KRX`, 미국 `ND`·`NY`·`NA` |

동일 종목의 날짜 중복, 미래 날짜, 잘못된 수치, 종목별로 서로 다른 상장일·이름·완전성 표시는 거부합니다. 오늘 행은 최고가에서 제외합니다. 전 거래일까지 최신 자료가 없거나 중간 거래일이 빠지면 가져오기 자체가 성공해도 매수 적격 상태가 되지 않습니다.

CSV의 완전성은 **제공자의 명시적 확인**입니다. 프로그램은 독립적인 데이터 공급자 검증을 수행하지 않으며, 상장일을 입력한 것만으로 `complete_from_listing=true` 확인을 대신하지 않습니다. 모의 화면에서 최고가 숫자만 직접 넣은 예제 이력은 실거래 매수에 사용할 수 없습니다.

## 실제 운영 전에 권장하는 확인

수수료 여유금·재매수 대기·최대 보유 종목 제한은 구현되어 있습니다. 실제 운영 전에는 계좌별 시세 권한과 전체 요청 종목의 구독 승인, 상장 이후 수정 이력의 출처, 미국 체결 시각의 시간대, 주문·취소·부분 체결 대조를 확인해야 합니다. 필요하면 유동성·거래대금·투자주의 종목 필터, 일일 손실 한도, 별도 알림과 운영 모니터링을 다음 개발 범위로 추가할 수 있습니다. 이 추가 기능들은 현재 구현된 기능으로 표시하지 않습니다.
